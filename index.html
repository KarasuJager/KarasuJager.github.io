The Huntmethodology

Five moves on every target, from a login form to an agent with tool access.

01

Research

Read the docs, the code and the stack before touching anything.

02

Recon

Map the attack surface: endpoints, roles, trust boundaries, what the client hides.

03

Analyze

Form a hypothesis about where it breaks, and why.

04

Validate

Prove it with controlled requests. A finding is real only when it reproduces.

05

Build

Turn it into tooling, and a report a developer can act on the same day.

OWASP Top 10 for LLM Applications
Current quarry · focus

Breaking LLM applications in production

I assess AI assistants deployed by large enterprises, including ones that call tools and APIs on the user's behalf. These are the classes I look for first.

LLM01Prompt injectionDirect and indirect instructions that override the system's intent, including payloads hidden in retrieved content.
LLM06Excessive agencySteering function calls into actions the user was never authorized to trigger.
LLM02Sensitive information disclosureGetting the model to return data from other users, internal systems or its context.
LLM07System prompt leakageExtracting hidden instructions, credentials and business rules from the prompt.
LLM05Improper output handlingModel output reaching a browser, shell or query without being treated as untrusted.

The Nestprojects

Tools written to make my own testing faster and more rigorous.

SONDA

Public

A reproducible HTTP differential testing toolkit. It mutates requests in a controlled way, fingerprints each response and keeps the evidence, so a suspected access-control or logic flaw becomes a diff anyone can rerun.

request mutation · response fingerprinting · evidence-driven investigation
github.com/KarasuJager/sonda →

ARGOS

Private · in development

A Python framework that orchestrates AI agents for security research. Built on a hexagonal architecture where every action an agent takes passes through explicit authorization, scope, grant and egress layers, so automation never leaves the rules of engagement.

Python · hexagonal architecture · agent orchestration

bb-alert

Public

Phone alerts the moment a new public bug bounty program launches on HackerOne, Bugcrowd or YesWeHack. Runs for free on a GitHub Actions schedule and rings me through Telegram, because the first hours of a new program are the best ones.

GitHub Actions · Telegram · Python
