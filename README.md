# karasujager.github.io

Personal portfolio of Manuel Miguel Fernandez-Gallego Olivares (KarasuJager).

## Publish
1. Create a public repo named exactly `KarasuJager.github.io`.
2. Upload `index.html` (and this README) to the root. The crow image is embedded, no other files needed.
3. Settings → Pages → Source: "Deploy from a branch" → `main` / `/ (root)`.
4. Live at https://karasujager.github.io in a minute or two.
